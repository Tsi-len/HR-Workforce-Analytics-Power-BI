HRIS & Workforce Financials Power BI Dashboard

## Executive Summary
An interactive 3-page Power BI dashboard designed for executive leadership to monitor headcount, recruitment pipelines, and payroll budget variances.

## Key Features & Insights
* **Headcount & Demographics:** Dynamic tracking of active headcount (8 employees), turnover rate (20.00%), and gender breakdown[cite: 2].
* **Recruitment Efficiency:** Time-to-hire metrics (40.50 days avg) and requisition funnel breakdown[cite: 2].
* **Financials & Payroll:** Waterfall variance modeling comparing base spend, benefits, and bonus costs against budgeted salary (-$4.24K variance)[cite: 2].

## Tech Stack
* **Tool:** Power BI Desktop
* **Language:** DAX, Power Query (M)
* **Data Architecture:** Star Schema modeling connecting HR master, recruitment, and payroll tables.
